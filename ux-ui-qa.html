Q3 What is your design process?
First, I understand the client's business goals, product vision, and project requirements.
Before starting any design, I carefully review the existing website or application, business documents, product requirements, and available content to understand the current system.
Then I discuss my understanding with my senior and junior team members. I like to hear different ideas and experiences because it helps me gain more knowledge and find the best solution before starting the design.
If I need more clarity, I discuss it with the stakeholders before starting the next step.
I also use AI tools like ChatGPT and Figma AI to generate ideas, improve content, explore design concepts, and speed up my design process. However, I always review and validate the output before using it in the final design.
Then I create user personas, user flows, and simple wireframes to show the user journey and how users will interact with the product.
Once the team reviews and approves the flow, I create high‑fidelity UI designs in Figma using Design Systems, Auto Layout, Components, Variables, and reusable patterns.
After completing the UI design, I review it with my UX team, developers, and stakeholders. We discuss the design, collect feedback, and make the required improvements.
Then I create a clickable prototype in Figma. I connect all the screens with buttons and navigation so users can experience the complete flow. I also add animations, hover effects, tooltips, transitions, and other interactions wherever needed. This helps users, stakeholders, and developers understand how the final product will look and work before development starts.
Next, I present the prototype to users and stakeholders for usability testing. Based on their feedback, I refine the design until everyone is satisfied.
Finally, I hand over the approved design to developers through Figma Dev Mode. I explain the design specifications and interactions and support the developers during implementation.
While designing the UI, I pay special attention to typography, color theory, color palettes, web colors, visual hierarchy, spacing, grid system, alignment, accessibility, and responsive design. I also define font family, font size, font weight, line height, letter spacing, text color, icons, buttons, components, and reusable patterns to maintain consistency across the product.
Before handing off the design, I prepare complete design specifications, including colors, typography, spacing, padding, margins, border radius, icons, images, interactions, and responsive behavior, so developers can implement the design accurately.

Q4 What is a Design System?
A Design System is a collection of reusable components, colors, typography, icons, spacing, and design guidelines. It helps designers and developers maintain consistency, save time, and build better products. In Figma, I use Components, Variants, Variables, and Team Libraries to create and manage the Design System.
Design System ମାନେ ହେଉଛି Button, Color, Font, Icon, Spacing ଏବଂ Design Rule ଭଳି Reusable Element ଗୁଡ଼ିକର ଏକ Collection। ଏହା ଦ୍ୱାରା ସମସ୍ତ Screen ରେ ଏକରକମ Design ରହେ, ସମୟ ବଞ୍ଚେ ଏବଂ Designer ଓ Developer ମାନେ ସହଜରେ ଏକାଠି କାମ କରିପାରନ୍ତି। Figma ରେ ମୁଁ Components, Variants, Variables ଏବଂ Team Library ବ୍ୟବହାର କରି Design System କୁ ତିଆରି ଏବଂ Maintain କରେ।
Q5 What are Figma Variables?
Variables are reusable values in Figma. They help manage colors, spacing, typography, border radius, and other design properties from one place. Variables make design systems scalable and easy to maintain.
Figma Variables ହେଉଛି Reusable Value, ଯାହାକୁ ଗୋଟିଏ ସ୍ଥାନରୁ Manage କରାଯାଇପାରେ। ଏହା ଦ୍ୱାରା Color, Spacing, Typography, Border Radius ଏବଂ ଅନ୍ୟାନ୍ୟ Design Property କୁ ଏକ ସ୍ଥାନରୁ ନିୟନ୍ତ୍ରଣ କରିହେବ। ଗୋଟିଏ Variable କୁ Update କଲେ, ସେହି ପରିବର୍ତ୍ତନ ସମଗ୍ର Design ରେ ସ୍ୱୟଂଚାଳିତ ଭାବରେ ଲାଗୁ ହୋଇଯାଏ। ଏହା Design System କୁ ବଡ଼ Project ପାଇଁ ସହଜରେ Manage ଏବଂ Maintain କରିବାରେ ସାହାଯ୍ୟ କରେ।
Q6 What is Auto Layout?
Auto Layout helps create flexible and responsive designs. When I change the content, the frame automatically adjusts its size and spacing. It also helps maintain consistency and saves design time.
Auto Layout ହେଉଛି Figma ର ଏକ Feature, ଯାହା Responsive ଏବଂ Flexible Design ତିଆରି କରିବାରେ ସାହାଯ୍ୟ କରେ। ଯେତେବେଳେ Content ବଦଳାଯାଏ, Frame ର Size, Padding ଏବଂ Spacing ସ୍ୱୟଂଚାଳିତ ଭାବରେ Adjust ହୋଇଯାଏ। ଏହା ଦ୍ୱାରା ସମସ୍ତ Screen ରେ Design ଏକରକମ (Consistency) ରହେ, Responsive Design ତିଆରି କରିବା ସହଜ ହୁଏ ଏବଂ Design କରିବାର ସମୟ ମଧ୍ୟ ବଞ୍ଚିଯାଏ।
Q7 Difference between Components and Variants?
A Component is a reusable design element, like a button, card, or input field.
Variants are different versions of the same component, such as Primary, Secondary, Hover, Active, or Disabled.
Using Components and Variants helps maintain consistency, saves time, and makes the Design System easier to manage.
Component ହେଉଛି ଏକ Reusable Design Element, ଯେପରି Button, Card, Input Field କିମ୍ବା ଅନ୍ୟ କୌଣସି UI Element, ଯାହାକୁ ବାରମ୍ବାର ବିଭିନ୍ନ Screen ରେ ବ୍ୟବହାର କରାଯାଇପାରେ।
Variant ହେଉଛି ସେହି ଏକେ Component ର ଭିନ୍ନ ଭିନ୍ନ Version କିମ୍ବା State, ଯେପରି Primary, Secondary, Hover, Active, Disabled ଇତ୍ୟାଦି।
Components ଏବଂ Variants ବ୍ୟବହାର କଲେ ସମଗ୍ର Design ରେ ଏକରୂପତା (Consistency) ରହେ, ସମୟ ବଞ୍ଚେ ଏବଂ Design System କୁ ସହଜରେ Manage ଏବଂ Maintain କରିହେବ।
Q8 How do you conduct User Research?
First, I understand the business goals and target users. Then I conduct user interviews, surveys, competitor analysis, and discuss with stakeholders to understand user needs and pain points. Based on the findings, I prepare user personas, user journeys, and user flows.
ପ୍ରଥମେ ମୁଁ Business Goal ଏବଂ Target User କିଏ, ସେଥିକୁ ଭଲଭାବରେ ବୁଝେ। ତାପରେ User Interview, Survey, Competitor Analysis କରେ ଏବଂ Stakeholder ଙ୍କ ସହ ଆଲୋଚନା କରି User ଙ୍କର ଆବଶ୍ୟକତା (Needs), ସମସ୍ୟା (Pain Points) ଏବଂ ଆଶା (Expectations) ବୁଝେ। ଏହି Research ରୁ ମିଳିଥିବା ସୂଚନା ଆଧାରରେ ମୁଁ User Persona, User Journey ଏବଂ User Flow ପ୍ରସ୍ତୁତ କରେ, ଯାହା ଆମକୁ User‑Centered Design ତିଆରି କରିବାରେ ସାହାଯ୍ୟ କରେ।
Q9 What is Usability Testing?
Usability Testing means testing the product with real users. It helps us identify problems, collect feedback, and improve the user experience before development or release.
Usability Testing ମାନେ ପ୍ରକୃତ User ଙ୍କ ସହ Product କୁ Test କରିବା। ଏହା ଦ୍ୱାରା User ମାନେ Product ବ୍ୟବହାର କରିବା ସମୟରେ କେଉଁଠି ସମସ୍ୟା ହେଉଛି, ତାହା ଜଣାପଡ଼େ। ସେମାନଙ୍କର Feedback ନେଇ ଆମେ Design କୁ Improve କରୁ, ଯାହାଦ୍ୱାରା Development କିମ୍ବା Product Release ପୂର୍ବରୁ User Experience କୁ ଆହୁରି ଭଲ କରିପାରିବା।
Q10 Difference between Wireframe, Mockup, and Prototype?
A Wireframe is a basic layout that shows the page structure, content placement, and user flow without colors or images.
A Mockup is the visual design of the product. It includes colors, typography, icons, images, and branding, showing how the final interface will look.
A Prototype is a clickable version of the design. It connects all the screens with interactions and navigation, allowing users and stakeholders to experience and test the complete user flow before development.
Wireframe ହେଉଛି ଗୋଟିଏ Basic Layout, ଯେଉଁଥିରେ Page ର Structure, Content କେଉଁଠି ରହିବ ଏବଂ User Flow ଦେଖାଯାଏ। ଏଥିରେ Color, Image କିମ୍ବା Visual Design ନଥାଏ।
Mockup ହେଉଛି Product ର Visual Design। ଏଥିରେ Color, Typography, Icon, Image ଏବଂ Branding ଥାଏ, ଯାହାଦ୍ୱାରା Final Interface କିପରି ଦେଖାଯିବ ତାହା ବୁଝିହେବ।
Prototype ହେଉଛି Design ର ଏକ Clickable Version। ଏଥିରେ ସମସ୍ତ Screen କୁ Interaction ଏବଂ Navigation ଦ୍ୱାରା Link କରାଯାଏ, ଯାହାଦ୍ୱାରା User ଏବଂ Stakeholder ସମ୍ପୂର୍ଣ୍ଣ User Flow କୁ ଅନୁଭବ କରିପାରନ୍ତି ଏବଂ Development ପୂର୍ବରୁ Product କିପରି କାମ କରିବ ତାହା Test କରିପାରନ୍ତି।
Q11 How do you create User Personas?
I create user personas based on user research, interviews, surveys, and business requirements. A persona includes the user's goals, behaviour, pain points, and expectations. It helps the team design products that solve real user problems.
ମୁଁ User Research, User Interview, Survey ଏବଂ Business Requirement ରୁ ମିଳିଥିବା ସୂଚନା ଆଧାରରେ User Persona ପ୍ରସ୍ତୁତ କରେ। ଏକ User Persona ରେ User ଙ୍କର Goal, Behaviour, Pain Point, Need ଏବଂ Expectation ରହିଥାଏ। ଏହା ଦ୍ୱାରା Team User ଙ୍କର ପ୍ରକୃତ ସମସ୍ୟା ଏବଂ ଆବଶ୍ୟକତାକୁ ଭଲଭାବରେ ବୁଝିପାରେ ଏବଂ ସେହି ଅନୁଯାୟୀ User‑Centered Product Design କରିପାରେ।
Q12 How do you work with Developers?
I work closely with developers throughout the project. I explain the design, share Figma Dev Mode, design specifications, assets, and interactions. If developers have any questions, I discuss them and provide support until the project is completed.
ମୁଁ Project ର ସମସ୍ତ ପର୍ଯ୍ୟାୟରେ Developer ମାନଙ୍କ ସହ ନିକଟରୁ କାମ କରେ। ମୁଁ ସେମାନଙ୍କୁ Design ବୁଝାଏ, Figma Dev Mode Share କରେ ଏବଂ Design Specification, Assets, Interaction ଏବଂ ଆବଶ୍ୟକ ସମସ୍ତ Detail ପ୍ରଦାନ କରେ। ଯଦି Development ସମୟରେ କୌଣସି ପ୍ରଶ୍ନ କିମ୍ବା ସମସ୍ୟା ଆସେ, ତେବେ ମୁଁ ସେମାନଙ୍କ ସହ ଆଲୋଚନା କରି ସମାଧାନ କରେ ଏବଂ Project ସଫଳତାର ସହିତ ସମ୍ପୂର୍ଣ୍ଣ ହେବା ପର୍ଯ୍ୟନ୍ତ Support କରେ।
Q13 Tell me about a challenging UX project.
One challenging project was redesigning an existing product with many usability issues. I conducted research, collected user feedback, simplified the user flow, and improved the navigation. After the redesign, the user experience became much better and easier to use.
ମୋର ଗୋଟିଏ Challenging Project ଥିଲା ଏକ ପୁରୁଣା Product କୁ Redesign କରିବା, ଯେଉଁଥିରେ ଅନେକ Usability ସମସ୍ୟା ଥିଲା। ପ୍ରଥମେ ମୁଁ User Research କରିଥିଲି, User ଙ୍କର Feedback ସଂଗ୍ରହ କରିଥିଲି ଏବଂ ସେମାନଙ୍କର ସମସ୍ୟା ବୁଝିଥିଲି। ତାପରେ ମୁଁ User Flow କୁ ସରଳ କରିଥିଲି, Navigation Improve କରିଥିଲି ଏବଂ ସମଗ୍ର User Experience କୁ ଆହୁରି ସହଜ ଏବଂ User‑Friendly କରିଥିଲି। Redesign ପରେ Product ବ୍ୟବହାର କରିବା ଅଧିକ ସହଜ ହୋଇଥିଲା ଏବଂ User Experience ରେ ଭଲ Improvement ଦେଖିବାକୁ ମିଳିଥିଲା।
Q14 How do you mentor junior designers?
I regularly review their designs, share constructive feedback, and help them improve their UX thinking, Figma skills, and design process. I encourage them to ask questions, share their ideas, and learn from every project. I always maintain a friendly and supportive environment so they feel comfortable discussing their challenges and continuously improving their skills.
ମୁଁ ନିୟମିତ ଭାବରେ Junior Designer ମାନଙ୍କର Design Review କରେ, ସେମାନଙ୍କୁ ଭଲ Feedback ଦିଏ ଏବଂ UX Thinking, Figma Skill ଓ Design Process କୁ Improve କରିବାରେ ସାହାଯ୍ୟ କରେ। ମୁଁ ସେମାନଙ୍କୁ ପ୍ରଶ୍ନ ପଚାରିବା, ନିଜର Idea Share କରିବା ଏବଂ ପ୍ରତ୍ୟେକ Project ରୁ ନୂଆ କିଛି ଶିଖିବା ପାଇଁ ସବୁବେଳେ ଉତ୍ସାହିତ କରେ। ମୁଁ ସବୁବେଳେ ଏକ Friendly ଏବଂ Supportive ପରିବେଶ ରଖିବାକୁ ଚେଷ୍ଟା କରେ, ଯାହାଦ୍ୱାରା Junior Designer ମାନେ ନିର୍ଭୟରେ ନିଜର ସମସ୍ୟା ଓ ଭାବନା Share କରିପାରନ୍ତି ଏବଂ ନିଜର Skill କୁ ଆହୁରି Improve କରିପାରନ୍ତି।
Q15 How do you build a Design System from scratch?
First, I understand the product requirements, business goals, and user needs. Then I define the design foundation, including colors, typography, spacing, grids, icons, and design guidelines. After that, I create reusable components, variants, variables, and common UI patterns in Figma. Finally, I publish the Team Library, document the Design System, and keep it updated as the product grows.
ପ୍ରଥମେ ମୁଁ Product Requirement, Business Goal ଏବଂ User ଙ୍କର ଆବଶ୍ୟକତାକୁ ଭଲଭାବରେ ବୁଝେ। ତାପରେ ମୁଁ Design ର ମୂଳ ଆଧାର (Foundation) ପ୍ରସ୍ତୁତ କରେ, ଯେପରି Color Palette, Typography, Spacing, Grid System, Icon ଏବଂ Design Guideline। ଏହା ପରେ ମୁଁ Figma ରେ Reusable Components, Variants, Variables ଏବଂ ସାଧାରଣ UI Pattern ତିଆରି କରେ, ଯାହାକୁ ସମସ୍ତ Project ରେ ପୁଣିଥରେ ବ୍ୟବହାର କରିହେବ। ଶେଷରେ ମୁଁ Team Library Publish କରେ, Design System ର Documentation ପ୍ରସ୍ତୁତ କରେ ଏବଂ Product ବଡ଼ ହେବା ସହିତ ଏହାକୁ ନିୟମିତ ଭାବରେ Update ଏବଂ Maintain କରେ।
Q16 What is Accessibility (WCAG)?
Accessibility means designing products that everyone can use, including people with disabilities. I follow good color contrast, readable text, keyboard navigation, proper labels, and alt text to make the design accessible.
Accessibility ମାନେ ଏପରି Product କିମ୍ବା Application Design କରିବା, ଯାହାକୁ ସମସ୍ତ User ସହଜରେ ବ୍ୟବହାର କରିପାରିବେ, ଅକ୍ଷମ (Disabled) User ମାନେ ମଧ୍ୟ। ମୁଁ Design କରିବା ସମୟରେ ଭଲ Color Contrast, ପଢ଼ିବାକୁ ସହଜ Font, Keyboard Navigation, ସଠିକ୍ Label, Alt Text ଏବଂ ସ୍ପଷ୍ଟ Focus State ଉପରେ ବିଶେଷ ଧ୍ୟାନ ଦିଏ, ଯାହାଦ୍ୱାରା ସମସ୍ତ User ସହଜରେ Product ବ୍ୟବହାର କରିପାରନ୍ତି।
Q17 What is Information Architecture?
Information Architecture is the way we organize content and navigation so users can easily find what they need. A clear structure improves the overall user experience.
Information Architecture ମାନେ ହେଉଛି Website କିମ୍ବା Application ର Content, Menu ଏବଂ Navigation କୁ ଠିକ୍ ଭାବରେ ସଂଗଠିତ (Organize) କରିବା, ଯାହାଦ୍ୱାରା User ସହଜରେ ନିଜକୁ ଦରକାର ଥିବା ସୂଚନା କିମ୍ବା Feature ଖୋଜିପାରିବେ। ଏକ ସ୍ପଷ୍ଟ ଏବଂ ସୁସଂଗଠିତ Structure User ଙ୍କର ଅନୁଭବକୁ (User Experience) ଭଲ କରେ, Navigation କୁ ସହଜ କରେ ଏବଂ User ଙ୍କର ସମୟ ବଞ୍ଚାଏ।
Q18 How do you handle difficult stakeholders?
First, I listen carefully to their feedback and understand their concerns. Then I explain my design decisions with user research and business goals. If needed, I discuss different options and work together to find the best solution.
ପ୍ରଥମେ ମୁଁ Stakeholder ଙ୍କର Feedback କୁ ଧ୍ୟାନର ସହିତ ଶୁଣେ ଏବଂ ସେମାନଙ୍କର ଚିନ୍ତା ଓ ଆଶାକୁ ବୁଝିବାକୁ ଚେଷ୍ଟା କରେ। ତାପରେ ମୁଁ User Research, User Need ଏବଂ Business Goal ଆଧାରରେ ମୋର Design Decision କୁ ସ୍ପଷ୍ଟ ଭାବରେ ବୁଝାଏ। ଯଦି ମତଭେଦ ଥାଏ, ତେବେ ମୁଁ ଭିନ୍ନ ଭିନ୍ନ Option ଉପରେ ଆଲୋଚନା କରେ ଏବଂ ସମସ୍ତଙ୍କ ସହ ମିଶି User ଏବଂ Business—ଉଭୟଙ୍କ ପାଇଁ ଭଲ ହେବାଭଳି ସର୍ବୋତ୍ତମ Solution ବାଛିଥାଏ।
Q19 How do you conduct Design Reviews?
I review the design with my UX team, developers, and stakeholders. We discuss usability, consistency, accessibility, and business requirements. I collect feedback, improve the design, and finalize it before development.
ମୁଁ UX Team, Developer ଏବଂ Stakeholder ଙ୍କ ସହ ମିଶି Design Review କରେ। ଆମେ Design ର Usability, Consistency, Accessibility ଏବଂ Business Requirement ଉପରେ ଆଲୋଚନା କରୁ। ସମସ୍ତଙ୍କର Feedback ସଂଗ୍ରହ କରି ଆବଶ୍ୟକ ପରିବର୍ତ୍ତନ କରେ ଏବଂ Design କୁ Improve କରେ। ସମସ୍ତଙ୍କର Approval ମିଳିବା ପରେ, ମୁଁ Design କୁ Finalize କରି Development ପାଇଁ ପ୍ରସ୍ତୁତ କରେ।
Q20 How do you prioritize features?
I discuss business goals with stakeholders, understand user needs, and identify high-priority features. I focus on features that provide the most value to users and the business.
ପ୍ରଥମେ ମୁଁ Stakeholder ଙ୍କ ସହ Business Goal ବିଷୟରେ ଆଲୋଚନା କରେ ଏବଂ User ଙ୍କର ଆବଶ୍ୟକତା ଓ ସମସ୍ୟାକୁ ବୁଝେ। ତାପରେ Business ପାଇଁ ଏବଂ User ପାଇଁ କେଉଁ Feature ସବୁଠାରୁ ଅଧିକ ମୂଲ୍ୟବାନ ଏବଂ ଜରୁରୀ, ସେଗୁଡ଼ିକୁ ପ୍ରାଥମିକତା (Priority) ଦିଏ। ମୁଁ ସବୁବେଳେ ସେହି Feature ଉପରେ ପ୍ରଥମେ କାମ କରିବାକୁ ଗୁରୁତ୍ୱ ଦିଏ, ଯାହା User Experience କୁ ଭଲ କରେ ଏବଂ Business Goal ପୂରଣ କରିବାରେ ସର୍ବାଧିକ ସାହାଯ୍ୟ କରେ।
Q21 How do you use AI in UX Design?
I use AI tools like ChatGPT and Figma AI to generate ideas, improve content, create wireframe suggestions, and speed up repetitive tasks. However, I always review the output before using it in the final design.
ମୁଁ ChatGPT, Figma AI ଏବଂ ଅନ୍ୟାନ୍ୟ AI Tool ବ୍ୟବହାର କରି ନୂଆ Idea ଖୋଜେ, Content Improve କରେ, Wireframe ପାଇଁ Suggestion ନିଏ ଏବଂ ବାରମ୍ବାର କରିବାକୁ ପଡ଼ୁଥିବା କାମ (Repetitive Task) କୁ ଶୀଘ୍ର ସମ୍ପୂର୍ଣ୍ଣ କରେ। କିନ୍ତୁ AI ଯାହା Suggestion ଦିଏ, ତାହାକୁ ମୁଁ କେବେ ସିଧାସଳଖ Final Design ରେ ବ୍ୟବହାର କରେ ନାହିଁ। ପ୍ରଥମେ ମୁଁ ତାହାକୁ Review କରେ, User ଙ୍କର ଆବଶ୍ୟକତା ଏବଂ Business Goal ସହ ମେଳ କରି ଯାଞ୍ଚ କରେ, ତାପରେ Final Design ରେ ବ୍ୟବହାର କରେ।
